How the Web Loads a Page

Introduction

This project explains how a web browser loads and displays a webpage using the Network tab.

Website used: https://trainingtrains.com

DNS Lookup
DNS converts a website domain name into an IP address so the browser can locate the web server.

HTML Request
The browser requests the HTML document from the server. The HTML provides the structure of the webpage.

Note: The HTML document request was not separately captured in this mobile inspection.

CSS Request
CSS files are requested to load the webpage's design, colours, fonts and layout.

Status observed: 200

JavaScript Request
JavaScript files are loaded to provide interactive features and functionality.

Status observed: 200

Image Requests
Image files such as PNG files are requested and loaded by the browser.

Status observed: 200

Final Rendering
The browser combines HTML, CSS, JavaScript and images to display the final webpage.

Conclusion

The Network inspection helped me understand how different resources are requested and loaded when opening a website.
